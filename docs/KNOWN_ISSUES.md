# 已知问题与使用边界

本文是当前状态，旧的本地验证记录不能代替重新运行测试。不要将合成指标描述为真实风机性能。

## 正式验收前仍需解决

1. **评估的部分审核处理**：仅排除了完全落在 unknown 的预测；跨 unknown 的预测仍使用完整区间计算 IoU、报警时长，可能产生大于 100% 的报警占比。
2. **正常区域的报警时长**：匹配成功的预测，其正常区重叠未计入误报时长，长报警可能得到过于乐观的指标。
3. **短事件评估**：已审核区域以 0.1 秒网格计算，极短区间可能丢失。评估应改用连续区间并重新定义边界容差。
4. **审核关联**：事件 ID 仍按音频 ID 和事件序号生成，跨模型/阈值运行可能碰撞。暂时每次运行使用独立输出及审核文件，不自动合并不同版本。
5. **合成数据独立性**：部分样本共享相同背景，且分别进入不同集合；仅适合作为集成测试，不适合作为无泄漏泛化评估。

## 模型和工程限制

- 当前没有 L2 故障分类模型，L1 分数不是可靠故障概率。
- 逐文件归一化可能削弱持续占据大部分录音的异常；没有未来上下文的实时部署需要重新设计特征。
- 训练先构建特征矩阵再限制拟合样本；大数据仍可能耗尽内存。阈值候选已受限，但后处理搜索仍应先用小验证集测量耗时。
- WAV 读取支持 8/16/32 位整数 PCM；不支持 24 位和浮点 WAV。多声道直接平均可能抵消反相信号。
- XGBoost 是否可用取决于依赖和平台，不能用 sklearn 测试结果代替 XGBoost 验证。
- 训练时自动校准异常会保留未校准模型；必须检查 `calibrated`、`target_reached` 和日志，不能只检查输出目录存在。
- 模型/缓存仅限可信来源；详见 `SECURITY.md`。
