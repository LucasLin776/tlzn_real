# 用「平稳区域」标注重新标定 L1

> **历史记录**：本文档记录的是旧批次上的历史实测，对应的 `runs/`、`reports/` 产物已在 0.11.0 清理时移除；B02–B04（旧「标异常」口径）录音也已删除，B05–B07 现位于 `数据/新一批/`。命令中的路径按新目录替换后再执行。

本文件记录新增的标注口径、拟合流程与 B05 上的结果。

> 历史 v3 标定记录保留。本次新增的正常样本模型见 [NORMAL_MODEL.md](NORMAL_MODEL.md)。
> 0.10.0 修复了空正常标注文件未生成整段异常的问题（涉及 B05-071），因此下方历史数值
> 不应与修复后结果直接横向比较。网格曾使用验证集选择参数，不能把该验证集称为独立测试。

## 1. 标注口径：标平稳，不标异常

`l1-test --labels-are-stable` 把 Audition 导出目录中的每一段解释为**平稳区间**：

- 区间内 → `normal`；
- 同一录音内其余时间 → `anomaly`（补集，短于 `min_gap_s=0.1 s` 的缝隙并入平稳，避免边界碎屑）；
- 因此可直接复用原有的时长/事件/拖尾指标，不需要第二套评估代码。

例：平稳 `[0.03,30.0]` 的整段平稳文件没有异常区间；平稳 `[0,3]`、`[6,10]` 的文件异常区间为 `[3,6]`。

## 2. 学到什么：平稳帧的分布尾部

拟合不训练权重，而是在**平稳帧**上估计每个判据的分布，把阈值放到它的尾部
（`wind_audio/fit.py`）：

| 参数 | 取值规则 |
|---|---|
| `trigger_change_z` | 平稳帧 `change_z` 的 `1-α` 分位（`α=1e-3`） |
| `trigger_exceed` | 平稳帧 `exceed` 的 `1-α` 分位 |
| `slow_ratio_trigger` | 平稳帧 `slow_ratio` 的 `1-α` 分位 |
| `quiet_excess` / `quiet_*_ratio` | 平稳帧的 98% 分位（保证释放通道可达） |
| `fluct_scale` / `drift_scale` | 平稳帧上 `波动/σ`、`漂移/σ` 的 `1-α_s` 分位（`α_s=1e-2`） |
| `stable_change_z` | 平稳帧 `peak_change` 的 `1-α_s` 分位 |
| `stable_band_frac` | 平稳帧「落在容差内的频带比例」的 `α_s` 分位 |

含义：**α 是"平稳帧被误判为有变化"的目标比例，α_s 是"平稳帧被误判为不稳定"的目标比例**。
平稳段的非平稳区（补集）不参与标定，只用于最后的评分。

`band_z` 由平稳帧上逐频带 `|ΔL|/σ` 的 `1-α` 分位给出，限幅 2–6。

## 3. 分段方式：`segment_mode`

`confirm_s` 的释放逻辑增加两种模式：

- `trigger`（旧）：变化触发事件，稳定确认后结束（过渡型窗口）；
- `state`（新增）：**事件就是"稳定判据不成立"的连续区间**，`state_enter_s` 提供进入迟滞，
  `confirm_s` 提供退出迟滞。非平稳是一个持续状态，这种分段才能覆盖整个非平稳区。

## 4. 拟合流程

```bash
python -m wind_audio l1-fit \
  --audio-dir /Users/shuoqinlin/Desktop/数据/B05/音频 \
  --labels    /Users/shuoqinlin/Desktop/数据/B05/标注 \
  --out config/l1_fit_b05.json \
  --report runs/l1_v3/fit_b05/report.json \
  --val-fraction 0.3 --alpha 1e-3 --alpha-stable 1e-2
```

- 按**时间顺序**切分：前 70% 拟合、后 30% 验证（相邻一分钟片段共享工况，随机切分会泄漏）。
- 候选网格比较 `segment_mode`、`confirm_s`、`noise_s` 等结构项；每个候选都重新做上面的分位标定。
- 选择标准是**验证集时长 F1**（目标是"非平稳区域"，不是点事件），时长准确率与事件 F1 作为并列裁决。
  最终报告只使用验证集一次。

## 5. B05 结果

B05 与 **B04 是同一批录音**（95/96 文件重合，B05 多出 B04 缺失的那一分钟），标注口径相反：
B04 标事件 298.5 s，B05 标平稳 2179 s / 非平稳 670 s；B04 的事件时间有 94% 落在 B05 的非平稳间隙内。
**因此 B05 不是 B04 的独立测试集**，两者只能作为同一会话的两种标注视角。

拟合流程在 B05 上（时间序切分：拟合 67 条 / 验证 29 条）：

| 指标 | 基线 v3（B02–B04 上调的参） | 拟合后 |
|---|---:|---:|
| 验证集时长 F1 | 0.419 | **0.688** |
| 验证集时长召回 / 精确率 | 0.273 / 0.900 | **0.690 / 0.686** |
| 验证集时长准确率 | 0.641 | **0.703** |
| 验证集覆盖率 | 0.158 | **0.473** |
| 验证集事件 F1 | 0.512 | **0.554** |
| 预测事件数（真值 72） | 131 | 58 |

全量 B05（含拟合集，仅供检查）：

| 指标 | 基线 | 拟合后 |
|---|---:|---:|
| 时长准确率 | 0.814 | **0.832** |
| 时长召回 / 精确率 | 0.222 / 0.914 | **0.600 / 0.652** |
| 覆盖率 | 0.140 | **0.438** |
| 事件 F1 | 0.520 | **0.576** |
| 报警拖尾 | 7 s | 128 s |

拟合后的关键参数：`band_z=4.94`、`trigger_change_z=2.17`、`fluct_scale=1.36`、`drift_scale=1.91`、
`stable_band_frac=0.81`、`stable_change_z=2.30`、`segment_mode=state`、`confirm_s=4.0`、`state_enter_s=0.2`。
帧级：平稳帧判为稳定 96.3%（拟合前 55.8%），非平稳帧判为不稳定 70.9%（拟合前 32.8%）。

## 6. 取舍与限制

- **召回与精确率的交换**：状态分段为了覆盖整段非平稳区，把时长召回从 0.27 提到 0.69，
  代价是时长精确率从 0.90 降到 0.69、拖尾从 7 s 增到 128 s（`confirm_s=4 s` 的确认延迟）。
  若更在意误报，把 `confirm_s` 调小或 `alpha` 调小即可，方向已在报告网格中列出。
- **同一会话**：拟合与验证都来自 B05 这一个会话，只能说明"在这个会话上学会了平稳的样子"，
  不能证明跨设备/跨季节泛化。
- **B04/B05 重叠**：两批音频相同，任何"用 B04 测 B05 模型"的结论都不成立。
- 非平稳帧仍有 29% 被判为稳定，这是当前特征的表达能力上限，不是阈值问题；
  要进一步提升需要更强的平稳性特征（例如跨频带的联合分布、长时谱形漂移）。
